Overview

Problem

Operations relied on separate tools and spreadsheets for classes, products, and fulfillment. Errors and duplicated work were common; the site felt disjointed.

Outcome

One system for schedules, orders, payments, and shipping. Admins use a single dashboard with standardized flows and customer history.

Responsibilities

  • Facilitated client ↔ team meetings; owned scope, backlog, and milestones.
  • Implemented rental equipment management and related admin workflows.
  • Defined MongoDB collections, indexes, and validation; assisted initial data migration.
  • Built reusable page templates and a consistent component/theme system.
  • Delivered and implemented customer management systems (admin views for contact info, bookings, and online orders).
  • Contributed extensively to UI/UX: layout, color system, interaction patterns.

Approach

  1. Discovery and scoping with the owner; translated requirements into a milestone plan.
  2. Created a Figma prototype to align on information architecture and visual direction.
  3. Modeled data for products, classes, rentals, and customers; added indexes for common queries.
  4. Implemented API routes and admin form flows; integrated Stripe and ShipStation webhooks.
  5. Staged deployments and content entry; prepared handoff documentation.

SEO & Marketing

Outcomes & Verification (privacy-safe)

  • Unified ops: one admin dashboard replaced spreadsheets and scattered tools.
  • Standardized flows: bookings, orders, and shipping use consistent, documented steps.
  • Customer history: contact info, bookings, and online orders in one view for staff.
  • Mobile-optimized: storefront and admin are responsive across phone and tablet.
  • Search foundations: complete Google Business Profile, consistent NAP, on-page SEO, and structured data.

How we measured success

  • Defined goals for booking completion, admin task time, and support issues.
  • Instrumented funnels and events; monitored search visibility and site health.
  • Reviewed Lighthouse checks and basic uptime/error monitoring.

Quantitative metrics (traffic, conversions, revenue) are available on request with client approval.

Testing

Strategy: layered QA using automated end-to-end tests, unit tests, and scripted manual passes. I wrote the WebDriver scripts, coordinated manual testing, and documented results.

  • Automated E2E: Selenium WebDriver + Mocha validating critical flows (customer CRUD & search, booking, checkout, admin auth/permissions). Latest run: 18 tests passing.
  • Unit tests: Jest for data validators, helpers, and API utilities.
  • Manual testing: step-by-step scripts covering edge cases (invalid email/phone, field length limits, duplicate detection); mobile viewport checks; issues triaged and retested.
  • Environment: macOS (M1), Chrome 135; seeded test DB; npm scripts to run suites.
  • Artifacts: test plan and result logs available on request.
