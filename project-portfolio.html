This Portfolio — Lightweight, Accessible Front-end

A small, fast portfolio designed to load instantly and stay easy to maintain. It uses semantic HTML, a lean CSS design system, and a few TypeScript-friendly helpers for interactions. No framework build step; deployed on GitHub Pages.

Role
  • Designer & Front-end Developer
Stack
  • HTML, modern CSS
  • JavaScript / TypeScript
  • GitHub Pages (static hosting)
Design system
  • CSS custom properties (color, radius, shadows)
  • Grid utilities for layout
  • Reusable cards, tags, chips
Goals
  • Fast, accessible, readable
  • Mobile-first, responsive
  • Clear information hierarchy

Overview

Why this approach

I wanted an instantly loading site on GitHub Pages that doesn’t require a framework or bundler. The structure favors clean HTML, a tiny CSS token system, and small vanilla JS/TS utilities.

What I focused on

  • Semantic markup and accessible navigation/breadcrumbs.
  • Consistent card components (radius, border, shadow, spacing).
  • Responsive grid for projects and sections with a steady reading rhythm.
  • Utility patterns for tags, chips, pills, and meta text.

Implementation

  1. Defined color tokens, radii, borders, and shadow in :root custom properties.
  2. Built a small grid and a reusable card component for content blocks.
  3. Added lightweight JS for clipboard, minor UI states, and links; authored to be TS-friendly.
  4. Optimized mobile first; checked contrast, focus, and keyboard paths.

Performance & Accessibility

  • No client framework; minimal JavaScript.
  • Readable type scale and contrast; keyboard-friendly controls.
  • Lean DOM and optimized images for fast loads on GitHub Pages.
