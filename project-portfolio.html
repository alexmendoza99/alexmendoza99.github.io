This Portfolio — Lightweight, Accessible Front-end

A small, fast portfolio built to highlight my front-end skills: semantic HTML, modern CSS (variables, grid, responsive scale), and a touch of JavaScript/TypeScript for interactions. Deployed to GitHub Pages with no framework overhead.

Role
  • Designer & front-end developer
Stack
  • HTML, modern CSS
  • JavaScript & TypeScript
  • GitHub Pages (static hosting)
Design system
  • CSS variables for color, radius, shadows
  • Grid & utility classes for layout
  • Reusable cards, tags, chips
Goals
  • Fast, accessible, readable
  • Mobile-first, responsive
  • Clear information hierarchy

Overview

Why this approach

I wanted a site that loads instantly on GitHub Pages and is easy to maintain. That means clean HTML, a small CSS design system, and tiny JS/TS helpers—no heavy frameworks or build steps required.

What I focused on

  • Semantic markup and accessible navigation/breadcrumbs.
  • Consistent card components (radius, border, shadow, spacing).
  • Responsive grid for projects/sections with clear reading rhythm.
  • Utilities for tags, chips, pills, and meta info.

Implementation

  1. Defined color tokens, borders, and shadow in :root CSS variables.
  2. Built a grid system and reusable “card” pattern for content.
  3. Wrote small JS for clipboard, scroll, and minor UI behaviors (TypeScript friendly).
  4. Optimized for mobile first; tested on narrow viewports and high-contrast settings.

Performance & Accessibility

  • No client frameworks; minimal JS.
  • Readable type scale and contrast; keyboard-friendly controls.
  • Light DOM and images; fast on GitHub Pages.
