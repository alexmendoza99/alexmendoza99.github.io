GPU Kernels — Histogram, Scan, Reduction

CUDA practice kernels with attention to memory coalescing, bank conflicts, and occupancy. Includes tests and simple benchmarks.

Role
Systems/parallel programming
Scope
Practice & benchmarking
Stack
CUDA, C++
Links
Repo (add link)

Approach

  1. Baseline single‑thread implementations for correctness comparisons.
  2. Parallel versions using shared memory and warp‑level primitives where appropriate.
  3. Measured occupancy and memory throughput; iterated on block sizes and tiling.
  4. Added unit tests and a simple timing harness.

Notes & Learnings

  • Histogram: avoided contention with privatization by block and a final reduction.
  • Scan: experimented with Blelloch vs. Hillis–Steele; compared bank conflict behavior.
  • Reduction: unrolling and warp shuffles reduced shared memory pressure.
